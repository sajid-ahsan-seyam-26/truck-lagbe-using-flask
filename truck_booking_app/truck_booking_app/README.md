# Truck Booking Flask App

A simple professional Flask project inspired by truck booking platforms.

## Features

- Customer truck booking form
- Driver job listing page
- Accept booking system
- Admin dashboard
- SQLite database
- Bootstrap UI
- Clean Flask project structure

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python run.py
```

Then open:

```text
http://127.0.0.1:5000
```

## Pages

- Home: `/`
- Book Truck: `/book`
- Driver Jobs: `/jobs`
- Dashboard: `/dashboard`
